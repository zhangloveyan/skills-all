# 通用任务类型

根据用户的简短描述选择一个主类型。混合请求先拆分，再为当前任务选择主类型。

| 类型 | 常见表达 | 默认权限 | 首要交付 | 状态变更前 |
| --- | --- | --- | --- | --- |
| 问答/读取 | 看下项目、解释代码 | 只读 | 事实、调用链、结论 | 无需变更 |
| 需求评审 | 评估需求、缺什么 | 只读 | 边界、冲突、验收、待确认项 | 确认实现范围 |
| 方案设计 | 给方案、怎么改 | 只读 | 文件范围、核心逻辑、风险、验证 | 确认落文档或实现 |
| 故障诊断 | 为什么报错、定位问题 | 只读 | 复现、时间线、根因、影响 | 确认修复范围 |
| 开发/修复 | 增加功能、修改、修复 | 可写 | 最小实现、测试、Diff 摘要 | 遵守适用确认规则 |
| 代码审查 | review、审核代码 | 只读 | 按优先级排列的问题 | 确认是否修复 |
| 测试/验证 | 跑测试、验证接口 | 默认只读 | 命令、结果、失败归因 | 确认是否修复失败 |
| 文档 | 更新文档、接口说明 | 可写 | 与事实一致的文档 | 遵守适用确认规则 |
| Git | 提交、推送、合并 | 状态变更 | 精确范围、提交或远端结果 | 每项操作单独确认 |
| 测试部署 | 部署测试环境 | 外部状态变更 | 指定版本、备份、验证结果 | 部署前确认 |
| 生产部署 | 部署生产 | 最高风险 | 已验证版本、回滚点、生产验证 | 独立任务并确认 |
| 数据库 | 迁移、清理、导入、切换 | 最高风险 | 备份、预演、比对、回滚 | 不可逆步骤逐项确认 |
| 生产事故 | 线上异常 | 先只读 | 影响、时间线、根因、止损方案 | 止损动作前确认 |

## 风险等级

- `R0`：纯问答、只读分析、无行为变化的说明。
- `R1`：局部展示、文案或低影响交互。
- `R2`：普通接口、局部业务逻辑或有限范围代码修改。
- `R3`：鉴权、计费、数据、缓存、异步任务、支付、部署和生产事故。

一次任务涉及多个等级时使用最高等级。项目 `AGENTS.md` 可以定义更严格的分类和确认要求。
